### 📘 Description  

**Welcome to English Janala – Learn English. Speak with Confidence!**  
<br/>
English Janala is a simple and interactive English learning web application built using **HTML, Tailwind CSS, and Vanilla JavaScript**. The platform is designed to help learners practice and improve their English skills through structured lessons and interactive content.

With a clean UI and responsive design, English Janala provides an easy and enjoyable learning experience for beginners and intermediate learners.

---

### ✨ Key Features  

- Structured English lessons for beginners  
- Grammar and vocabulary practice  
- Interactive quizzes using JavaScript  
- Clean and user-friendly interface  
- Fully responsive design using Tailwind CSS  
- Lightweight and fast (no frameworks used)  
- Mobile-friendly layout  
- Easy to extend and customize  

---

### 🛠️ Technologies Used  

- **Markup:** HTML5  
- **Styling:** Tailwind CSS  
- **Scripting:** Vanilla JavaScript  
- **Design:** Mobile-First & Responsive Layout
